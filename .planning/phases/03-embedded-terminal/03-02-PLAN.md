**1. Create `TerminalPanel/themes.ts`:**

Export `DARK_THEME` and `LIGHT_THEME` objects matching the GitHub Primer palette from the research. These are `ITheme` objects for xterm.js. See 03-RESEARCH.md "Pattern 6" for exact hex values.

**2. Create `TerminalPanel/useTerminal.ts`:**

A custom hook `useTerminal(containerRef, sprite, org, theme, active)` that:
- Creates a `Terminal` instance with sensible defaults: fontFamily `'ui-monospace, "Cascadia Code", "Fira Code", monospace'`, fontSize 13, cursorStyle `'bar'`, scrollback 5000, theme from DARK_THEME/LIGHT_THEME based on `theme` param.
- Loads FitAddon, Unicode11Addon.
- On mount: calls `term.open(container)`, then loads WebglAddon in try/catch (fallback to canvas), then `requestAnimationFrame(() => fitAddon.fit())`, then calls `window.spriteAPI.terminalOpen(sprite, org, term.cols, term.rows)`.
- Wires `term.onData` to `window.spriteAPI.terminalInput(sprite, data)`.
- Wires `window.spriteAPI.onTerminalOutput(sprite, ...)` to `term.write(data)`. Also calls store `updateTerminalTabStatus(sprite, 'connected')` on first data received.
- Wires `window.spriteAPI.onTerminalExit(sprite, ...)` to write `'\r\n[Connection closed]\r\n'` and update tab status to `'disconnected'`.
- Creates a `ResizeObserver` on the container that calls `fitAddon.fit()` then `window.spriteAPI.terminalResize(sprite, term.cols, term.rows)`. Add a 100ms debounce to avoid excessive resize calls.
- Cleanup: disposes term.onData, removes output/exit listeners, disconnects ResizeObserver, calls `window.spriteAPI.terminalClose(sprite)`, calls `term.dispose()`.
- Responds to theme changes: update `term.options.theme` without remounting (separate useEffect on `theme`).
- IMPORTANT: Does NOT import `@xterm/xterm/css/xterm.css` here — that goes in TerminalTab.tsx or the component that mounts the terminal.
- Returns `{ termRef }` so TerminalTab can access the terminal instance if needed (e.g., for focus).

**3. Create `TerminalPanel/TerminalTab.tsx`:**

A React component receiving `{ sprite: SpriteInfo, org: string, active: boolean }` props.
- Imports `@xterm/xterm/css/xterm.css` (critical — without this, terminal is invisible).
- Uses `useTheme()` from `next-themes` to get `resolvedTheme` ('dark' | 'light').
- Creates a `containerRef = useRef<HTMLDivElement>(null)`.
- Calls `useTerminal(containerRef, sprite.name, org, resolvedTheme === 'dark' ? 'dark' : 'light', active)`.
- Renders a div with ref, using `display: active ? 'block' : 'none'` to preserve PTY session across tab switches (NOT conditional rendering — see Pitfall 6 in research).
- The div must have `width: 100%` and `height: 100%` to fill the panel.

NOTE: If `next-themes` ThemeProvider is not yet wrapping the app in App.tsx, check and add it. The research notes this may be missing. Wrap the app's root component with `<ThemeProvider attribute="class" defaultTheme="system" enableSystem>`.

**4. Create `TerminalPanel/TerminalPanel.tsx`:**

The side panel container with tab bar. Reads from Zustand store: `showTerminalPanel`, `terminalTabs`, `activeTerminalSprite`, `setActiveTerminalSprite`, `removeTerminalTab`, `setShowTerminalPanel`.

Layout:
- Tab bar at top: horizontal row of tabs, each showing sprite name + colored status dot (green=connected, yellow=connecting, gray=disconnected) + X close button.
- Close-all X button in the top-right corner of the tab bar that calls `setShowTerminalPanel(false)` and removes all tabs.
- Below tab bar: flex-1 container holding all TerminalTab instances (all rendered, visibility toggled via `active` prop).
- Clicking a tab calls `setActiveTerminalSprite(spriteName)`.
- Clicking X on a tab calls `removeTerminalTab(spriteName)`.

Read `org` from the sprite info in the tab (each tab's `sprite` object has `organization` field).

Style using Tailwind classes matching the Linear aesthetic: border-l on the panel, border-b on tab bar, text-xs for tab labels, muted colors, hover states.
