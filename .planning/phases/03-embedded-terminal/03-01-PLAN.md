**1. Create `src/main/pty-manager.ts`:**

A `Map<string, IPty>` keyed by sprite name manages PTY sessions. Exports:

- `openSession(spriteName, spriteOrg, cols, rows, onData, onExit)` — kills existing session for sprite if any, spawns `sprite console -s <name> -o <org>` with `name: 'xterm-256color'`, cwd `process.env.HOME`, env `process.env`. Registers `onData` and `onExit` callbacks. Stores in sessions map.
- `writeToSession(spriteName, data)` — writes to PTY if session exists
- `resizeSession(spriteName, cols, rows)` — resizes PTY if session exists
- `killSession(spriteName)` — kills PTY and removes from map
- `killAllSessions()` — kills all active PTY sessions (for app cleanup on quit)

Use `import * as pty from 'node-pty'`. The `pty.spawn()` call uses `'sprite'` as the command (not `cs2`), with args `['console', '-s', spriteName, '-o', spriteOrg]`.

**2. Create `src/main/ipc/terminal.ts`:**

Follow the `registerDispatchHandlers` pattern exactly. Export `registerTerminalHandlers(win: BrowserWindow)`:

- `ipcMain.handle('terminal:open', ...)` — calls `openSession()` with `onData` pushing to `win.webContents.send(\`terminal:output:${sprite}\`, data)` and `onExit` pushing to `win.webContents.send(\`terminal:exit:${sprite}\`, { code })`. Returns `{ ok: true }`.
- `ipcMain.handle('terminal:close', ...)` — calls `killSession(sprite)`. Returns `{ ok: true }`.
- `ipcMain.on('terminal:input', ...)` — calls `writeToSession(sprite, data)`. Fire-and-forget (no handle/invoke) to avoid Promise overhead on every keystroke. Payload: `{ sprite: string, data: string }`.
- `ipcMain.on('terminal:resize', ...)` — calls `resizeSession(sprite, cols, rows)`. Fire-and-forget. Payload: `{ sprite: string, cols: number, rows: number }`.

**3. Edit `src/main/index.ts`:**

Add `import { registerTerminalHandlers } from './ipc/terminal'` and call `registerTerminalHandlers(win)` after the existing handler registrations.

Also add cleanup on `app.on('before-quit')`: import `killAllSessions` from pty-manager and call it to prevent orphaned PTY processes.
